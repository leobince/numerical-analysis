# Interpolation and Curve Fitting Project

## Introduction

This project implements various interpolation and curve fitting tasks using reusable C++ classes. The tasks include:

- Newton Interpolation
- Runge's Phenomenon and Chebyshev Nodes
- Hermite Interpolation for Car Motion Prediction
- Newton Interpolation for Larvae Growth Prediction
- Curve Fitting of a Heart-Shaped Curve using Cubic Bézier Curves

The codebase is modular, using classes such as `Polynomial`, `InterpCondition`, and `Interp` for efficient and reusable computation.

## Requirements

- **C++ Compiler**: GCC or any C++11 compliant compiler
- **GNU Make**
- **Gnuplot**: For plotting graphs
- **LaTeX**: For compiling the report (pdflatex)

## How to Build and Run

1. **Clone or Download the Repository**

   Ensure that all the `.cpp`, `.h`, `.plt`, `Makefile`, and `Report.tex` files are in the same directory.

2. **Compile and Run the Programs**

   Open a terminal and navigate to the project directory.
